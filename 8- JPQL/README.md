
# Trabajo Practico Grupal: Mapeo Objeto Relacional - ORM - JPA - Hibernate 

El objetivo de esta práctica es implementar el mapeo objeto-relacional (ORM) mediante
JPA/Hibernate sobre el modelo de dominio provisto y configurar el motor de persistencia
hacia una base de datos relacional.
